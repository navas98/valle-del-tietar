# Valle Vivo (22)

Prompt para Claude Design — Sotillo está vivo

Quiero que diseñes la interfaz completa de una plataforma web llamada “Sotillo está vivo”, dedicada a impulsar el turismo, la hostelería y el comercio local del Valle del Tiétar después de los incendios sufridos en la zona.

Objetivo visual

La web debe transmitir:

Naturaleza

Recuperación

Esperanza

Comercio local

Turismo

Cercanía

Modernidad

El incendio es el contexto que explica el nacimiento del proyecto, pero NO quiero una web triste, dramática ni centrada visualmente en el fuego.

El mensaje visual debe ser:

“El Valle sigue vivo y merece la pena volver.”

Quiero una estética moderna, premium y muy visual, similar a una plataforma turística contemporánea, evitando completamente el aspecto de una web institucional o municipal.

Dirección artística

Utiliza fotografías y vídeos grandes como protagonistas.

Paleta inspirada en el Valle del Tiétar:

Verde bosque oscuro como color principal.

Verde natural secundario.

Blanco cálido / crema para fondos.

Tonos tierra.

Terracota o naranja quemado únicamente como color de acento.

Texto casi negro sobre fondos claros.

No abuses de gradientes.

Utiliza bastante espacio en blanco.

Las fotografías deben tener mucho peso visual.

Usa bordes redondeados moderados, aproximadamente 12–16 px.

Sombras muy suaves.

La interfaz debe sentirse limpia y natural, no como un dashboard SaaS.

Tipografía

Utiliza una sans serif moderna como Manrope, Inter o similar.

Los títulos deben ser grandes y contundentes.

Especialmente en el Hero quiero una jerarquía tipográfica fuerte.

Navbar

Navbar inicialmente transparente sobre el vídeo del Hero.

2. Por qué existe este proyecto

Título:

No utilizar imágenes dramáticas del incendio.

Utilizar fotografías actuales del Valle y sus negocios.

Diseña esta sección con una composición editorial moderna: fotografía grande + texto.

Experiencia de usuario

Quiero microinteracciones discretas y elegantes.

Al hacer scroll:

fade-in;

pequeñas transiciones verticales;

imágenes que aparecen progresivamente.

Hover sobre fotografías:

scale muy ligero;

transición 200–300 ms.

Evita animaciones exageradas.

La página debe sentirse rápida.

Responsive

Diseña primero pensando en desktop pero crea una experiencia móvil excelente.

En móvil:

Hero fullscreen.

Navbar simplificado.

Menú hamburguesa.

Categorías fácilmente navegables.

Tarjetas en carrusel cuando tenga sentido.

Mapa adaptado.

Vídeos cómodos de reproducir.

Importante

NO quiero:

aspecto de web institucional;

aspecto de plantilla WordPress;

aspecto de dashboard SaaS;

exceso de iconos;

exceso de gradientes;

colores demasiado saturados;

diseños genéricos de IA;

textos enormes ocupando todas las secciones;

imágenes dramáticas del incendio.

Quiero que el usuario entre y piense:

“Quiero ir al Valle del Tiétar.”

El diseño debe convertir la recuperación del Valle en una experiencia positiva basada en descubrir lugares, personas y negocios.

Prioriza siempre:

Fotografía + naturaleza + historias humanas + comercio local + exploración.
